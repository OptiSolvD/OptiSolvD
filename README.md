## 👨‍💻 About Me

I'm a Computer Science undergraduate at **IIT Gandhinagar** who loves turning an idea into a complete, working product — from the frontend and backend, to authentication and databases, all the way to containers, CI/CD and cloud deployment.

- 🎓 **B.Tech CSE** @ IIT Gandhinagar
- 🌐 **Full-Stack Developer** specializing in the **MERN stack** and **Next.js**
- 📱 **Cross-platform mobile developer** using **React Native**
- ☁️ **DevOps & Cloud** — Docker, GitHub Actions, AWS EC2, Kubernetes (Minikube)
- 🧮 Strong foundation in **Data Structures & Algorithms** using **C++**
- 🤖 Exploring **AI Agents, RAG, LangChain & LangGraph**
- 🏗️ Interested in **System Design** and **Agentic Systems**
